# Juan D. Carranza — Personal Portfolio

Personal portfolio website showcasing my background in civil engineering, construction management, project experience, and interest in emerging construction technologies.

## Framework and Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

The project was developed locally using Visual Studio Code with assistance from ChatGPT throughout the development process.

## Setup Instructions

To run the website locally:

1. Install Node.js.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project directory.
4. Install the project dependencies:

   npm install

5. Start the development server:

   npm run dev

6. Open http://localhost:3000 in a web browser.

## Key Files

- `app/page.tsx` — Main portfolio page, content, interactions, galleries, and responsive layouts.
- `app/layout.tsx` — Root layout, metadata, and site configuration.
- `app/globals.css` — Global styling and theme variables.
- `app/icon.png` — Website favicon.
- `public/images/` — Portfolio and project images.
- `public/videos/` — Video assets used in the AI + Construction section.
- `public/resume.pdf` — Résumé linked from the portfolio.

## Deployment

The project uses Git and GitHub for version control. The production website is deployed through Vercel from the GitHub repository.

## AI and Development Tools

ChatGPT was used as the primary AI development assistant for setup guidance, coding, debugging, responsive development, design iteration, testing, and deployment guidance. Gemini was used to generate and explore selected visual and motion assets.
